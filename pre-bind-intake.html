One workflow for every type of insurance

The platform was built for marine insurance only. When aviation, construction and political violence cover came on board, each one would have needed its own tool. So I redesigned the journey, from the first request to the agreed policy, as one shared base that any type of insurance and any client can set up their own way.

09 · What I learned

Notes I'm taking to the next platform

  1. Listen first

    The clearance step was not in any brief. It came from aviation clients telling us how they really worked.

  2. Make differences settings

    When a line worked differently, I asked if it could be a setting. Clearance became a switch, not a second product.

  3. Fix once, fix everywhere

    An 8-click filter is a small annoyance on one line. Fixed in the base, it was fixed for every line.

  4. Measure from day one

    We aimed to halve checking time but never tracked it. Next time, I would agree how to measure before launch.

Marine had a flow built for one line. I left a base that four types of insurance run on, where a new line is a setup job, not a rebuild.
