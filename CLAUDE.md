# Project rules

- Subtext, sublines, intros and body paragraphs under headings must use the full available width. Never cap them with max-width (e.g. 60ch) that leaves empty space on the right, even if a prompt asks for "max ~60 characters per line". Only headlines may be constrained.
- Copy: plain English, short sentences, no em/en dashes, no emojis, past tense for the user's role, title is "Staff UX Designer".
- Product mockups keep their own blue interface palette (RiskLane). Never apply site green inside mockups.
